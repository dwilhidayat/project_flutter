# laundry_app
Laundry App Planner

App Description:
A simple Flutter  app that designed  to helps users plan their laundry loads. Users can input the number of clothes and machine capacity, then select wash temperature and cycle type to calculate total laundry time and number of loads.


Input  Process  Output
Input
•	Number of clothes
•	Machine capacity
•	Temperature (low / medium / high)
•	Cycle type (delicate / normal / heavy)

Process 
•	Validate numeric input
•	Compute loads = clothes / capacity
•	Adjust base time based on temperature 
•	Mulltiply loads × adjusted base time

Output
•	Total laundry time (minutes)
•	Number of loads
•	Validation message (invalid input)

Validation:
Uses double.tryParse() for safe numeric conversion. Checks if inputs are empty or less than or equal to zero, and displays 'invalid input' message without crashing the app.
